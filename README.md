# Liberty Tree Compliance

Production website for Liberty Tree Compliance, a boutique compliance evidence
services firm focused initially on PFAS Evidence Packets for manufacturers.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Route metadata, sitemap, and robots support

## Local Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```
